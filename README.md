# portfolio

Quellcode meiner Portfolio-Website. Statische Seite aus HTML, CSS und JavaScript, kein Build-Schritt.

Live: <https://henriloehlein.github.io/portfolio/>

## Aufbau

| Pfad | Inhalt |
|---|---|
| `index.html` | die Seite, inklusive der Case-Study-Inhalte |
| `css/`, `js/` | Design-System und Interaktionen |
| `assets/img/` | Bilder der Seite |
| `preview-*.html` | Entwürfe zum Testen, nicht Teil der Live-Seite |
| `docs/` | Arbeitsnotizen zum Projekt |

Ein Push auf `main` veröffentlicht automatisch über GitHub Pages.
